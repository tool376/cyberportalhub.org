🧬 File Type / Signature Identifier

What is a file really? The name may say "photo.pdf" while the inside is a virus (EXE). This tool looks inside the file and tells you.

How to use
  1. Choose any file below (PDF, photo, APK, ZIP, anything) → the file is not opened, only checked.
  2. The result shows the real type, size and SHA-256 fingerprint.
  3. If you see a red warning, do not open or install the file, and do not trust whoever sent it.
🟢 Green: the name and the real type match.
🟡 Yellow: be careful — the file can run code or was not recognised.
🔴 Red: fake or double extension — do not open the file.
The fingerprint (SHA-256) lets you prove later that the file has not been changed. Note it down in your complaint.

🔳 QR Code Decoder

Scanning a QR can open a link or take money. Upload the QR image here and see what is inside first, without opening anything.

How to use
  1. Choose a screenshot or photo of the QR (or paste it with Ctrl+V).
  2. The tool shows the link / UPI / text inside — the link is never opened automatically.
  3. Read the yellow/red warnings. If in doubt, do not open it, and call 1930 or report at cybercrime.gov.in.
🟢 Green: no obvious danger in the link (still check the domain yourself).
🟡 Yellow: UPI payment, shortened link, or no https — be careful.
🔴 Red: look-alike domain, IP address, "@" in the link, or an APK download.
Remember: you never need to scan a QR or enter your UPI PIN to receive money. Anyone who says "scan this and money will arrive" is a fraudster.

This tool is for assistance only, not legal advice. Always keep your original files.
