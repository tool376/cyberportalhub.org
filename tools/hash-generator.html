Forensic Hash Generator

Generate MD5, SHA-1 and SHA-256 hashes for files and ZIP archives. Select or drop multiple files and folders at once — every file and every folder gets its own named hash entry (a folder gets one deterministic folder hash).

Nothing leaves this device. Files and text are hashed entirely in your browser. Nothing is uploaded.
FORENSIC ACQUISITION DETAILS
Browser security does not expose the actual computer hostname or MAC address. Enter them manually when required for a forensic record. Platform and IST timestamp are captured automatically.
